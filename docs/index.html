Playing in 3 minutes

The launcher handles installation and updates for you.

1

Download the launcher

Grab VoxWorldLauncher.exe and run it. No installer, it just opens.

2

Click Install

The launcher downloads the latest version of the game automatically — and keeps it up to date from then on.

3

Press Play

The game starts with the official server address pre-filled. Pick a name, create your character, and jump in.

💡 Windows SmartScreen warning? That notice appears because this open-source build isn't code-signed. Click More info → Run anyway and it will start normally.
