What is Vox World?

Vox World drops you into a procedurally generated fantasy continent that keeps living even while you're away — towns trade, caravans travel, and creatures roam. Hunt towering bosses in deep dungeons, gather and craft your way to better gear, ride airships between far-flung settlements, and do it all together with friends on the official server.

Ready to start your adventure?

Vox World runs through its own launcher — one small download that installs the game and keeps it up to date.

Get the Vox World Launcher

Download the launcher, click Install, then Play — it connects you to the official server automatically. That's all there is to it.

⬇ Download Launcher (Windows · 6 MB)

The launcher downloads the full game (~370 MB) on first install.

1

Run the launcher

No installer needed — VoxWorldLauncher.exe just opens.

2

Click Install

The launcher fetches the latest version of the game automatically — and keeps it updated from then on.

3

Press Play

The game opens with the official server pre-filled. Pick a name, create your character, and jump in.

💡 Windows SmartScreen warning? That notice appears because this open-source build isn't code-signed. Click More info → Run anyway and it will start normally.
